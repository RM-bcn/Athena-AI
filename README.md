# Athena-AI

My concierge for my upcoming island hop trip.

## Getting Started

This project uses [Bun](https://bun.sh) and [Vite](https://vitejs.dev).

### Prerequisites

- Bun
- Node.js

### Install

```sh
bun install
```

### Run

```sh
bun run dev
```

### Build

```sh
bun run build
```

## Project Structure

- `src/` - client source code
- `api/` - serverless functions
- `server.ts` - server entry point
- `assets/` - static assets
